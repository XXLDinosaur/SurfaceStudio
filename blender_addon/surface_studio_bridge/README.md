# Surface Studio for Blender

Blender 4.2+ 本地材质库连接插件，已在 4.2.4 LTS 和 5.1.2 实测。

## 使用

1. Blender 3D 视图按 N，进入 Surface Studio 标签。
2. 选中需要赋材质的网格模型，点击「打开材质库」。
3. 点击任意材质卡片，详情面板中检查目标模型名称。
4. 点击「赋予到 Blender」，等待成功提示，再返回 Blender 查看。

对象模式给所有选中的网格模型的全部面赋材质。编辑模式只改选中的面，其他面保留。可按 Ctrl + Z 撤销整个赋予操作（包括自动 UV）。原材质槽保留。

## 选项

- 平铺次数：UV 贴图重复频率。
- 自动 UV：对象模式下无 UV 的网格使用 Smart UV Project；已有 UV 不重做。编辑模式无 UV 时会提示先展开。
- AO：与颜色贴图相乘。
- 高度凹凸：高度贴图接入 Bump；不会添加细分或改变模型几何。
- 翻转法线绿色通道：将 DirectX 法线转换为 Blender 使用的 OpenGL 方向。默认不翻转。

使用实际贴图建立 Principled BSDF。颜色为 sRGB，法线、粗糙度、AO 等数据通道为 Non-Color。同一材质和选项可复用节点。贴图以本地路径引用，不会自动打包进 blend；移动工程时需保持贴图可访问或手动「打包资源」。

## 安装到其他 Blender

编辑 → 偏好设置 → 插件 → 右上角菜单 → 从磁盘安装，选择 surface_studio_bridge.zip 并启用。
插件偏好设置中的路径选择 Surface Studio.exe。应用目录需可写（连接文件保存在 data/blender）。

## 工作方式

通过本机 JSON 邮箱连接，无云服务，不执行外部脚本。场景操作在 Blender 主线程执行。30 秒未接收的请求会过期；选中对象或选中面变化后会拒绝旧请求。多个 Blender 窗口可在材质库中分别选择。

只处理网格模型。链接自其他文件的只读数据需先本地化；编辑模式下共享网格需先使其独立。对象模式会为目标对象建立独立网格副本，避免改变未选中的共享实例。
