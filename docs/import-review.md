# 导入自动检查

SS 内置离线检查，随首次建库、导入后的扫描、保存设置重新扫描及顶部刷新自动执行，无需外部脚本、联网服务或再次请求助手处理。新增文件后仍需触发扫描，本功能不监视硬盘上的实时文件变化。

在「材质库设置 → 导入自动检查」查看最近一次检查的时间和数量。

- 保留素材自带的 Preview；没有 Preview 时优先选择已识别的颜色图（Albedo / BaseColor / Diffuse），避免将 AO 图当成材质外观。
- 植物拼版全部收录，包括叶片、枯枝、植物碎屑等。识别仅用于统计，不再排除任何植物拼版；地表材质和其他拼版也正常收录。
- 自动分类使用本地名称词库及素材分类元数据等信息，不依赖在线翻译。手动分类优先；Blender 原生导出材质仍按原有流程进入未分类。
- 无法确认分类的素材保留在未分类。已分类、待确认和手动分类数量按当前库实时计算。

“采用颜色图预览”是本次扫描选用颜色图的材质数量，不表示原图损坏或刚刚修复的数量。“检查图片目录”仅统计普通材质库；已分类、待确认统计当前全部入库素材。

检查摘要随索引保存。旧索引缺少检查记录，或检查规则版本发生变化时，软件启动后在后台重新检查；正常启动直接复用当前索引。原素材、收藏、配置和手动分类不会因检查被覆盖。
