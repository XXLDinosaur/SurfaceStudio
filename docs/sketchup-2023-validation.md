# SketchUp 2023 本机补测

日期：2026-11-21。主程序：SketchUp Pro 2023 23.1.340，Ruby 2.7.7。SS 接收插件：0.2.1（与 1.8.1 安装包内插件一致）。测试时本机运行 SS 1.8.0；本轮没有将“已发布 1.8.1”等同于已安装。

## 本机问题与处理

安装位置为自定义目录。本机新增 SU 2023 后，其对应的用户 Plugins 目录没有 SS 接收插件。安装过其他年份的 SU 插件不会自动覆盖后来安装的版本。

用户完成首次启动条款并保存关闭 SU 后，使用当前安装包中的插件，为 2023 单独执行安装并校验；不修改其他版本。随后在新的独立测试模型中确认扩展正常自动加载、接收心跳更新。插件兼容代码在本次测试中未发现需要修改的错误。

此原因仅解释本机检测到的情况，不代表其他反馈者一定具有相同原因。

## 真实应用验证

- SU 2023 自带 API 创建独立空白模型，通过 Ruby 启动脚本运行测试；不操作用户当前工程，不自动操作鼠标键盘。
- 验证已安装的插件自动加载，不依赖直接加载开发源码替代安装流程。
- 使用运行中的 SS HTTP 接口创建任务，经 SU 进程收件目录和实际定时监听器接收。
- 8 张实际单图全部赋予成功，核对模型材质实际引用的颜色文件名；包括中文名称、JPG、PNG、JPEG、同名不同扩展名。
- 1 组实际 PBR 材质颜色图赋予成功，SU 2023 跳过不支持的 PBR 附加通道。
- 纯法线任务返回不支持错误，核对前后材质数量和模型所用贴图不变。
- 125% 显示缩放环境中，物理尺寸与按比例缩放的坐标输入均通过接收和拾取验证。

没有执行完整鼠标跨窗口拖放手势；没有将 API 接收、拾取和赋材质测试表述为完整手势测试。2024、2026 的原有模拟测试范围不因本次补测而升级为真机验证。测试记录与本机材质名称留在忽略的本地测试目录，不上传私人素材。

## 新增 SU 版本后的操作

1. 先完成该版本 SU 的首次启动，进入模型后保存关闭。
2. 重新运行 SS 安装器，勾选实际检测到的该年份 SU；或在该版本的扩展程序管理器中安装 `SurfaceStudio-SketchUp.rbz`。
3. 重新打开对应 SU。若扩展未加载，检查扩展程序管理器中的启用状态和扩展加载策略，不要仅重复刷新 SS。
4. 从桌面版 SS 卡片预览图拖到模型视口中的面、组或组件；网页访问 SS 不提供桌面原生拖出。
