# HDR 环境使用指南

本功能属于 SS 1.8.0 正式版，配套 Blender 插件 1.4.0。

## 名称自动分组

展开侧栏 HDR，可以看到天空、摄影棚、室内、街道与城市、森林与公园、海边与水域、山地与岩石、草地与田野、工业场景、沙漠、雪地与其他环境。只显示当前一级分类中实际有素材的分组。已有自定义分类不会重复出现在其他类型下；即使某分组暂时为空，其记录仍保留在分类选择器中，可再次归入素材。

分类使用随软件提供的本地中英文名称词库，在扫描和读取已有索引时统一执行。编号、分辨率和格式不会单独创建内容组。比如 `forest_road_02_4k.hdr` 与同名 EXR 都进入森林与公园；`city_night_4k` 进入街道与城市。明确摄影棚、纯天空和室内等线索优先，日出、日落等时间词在没有具体场景线索时归入天空。

每次后续导入或重新扫描新文件，都会再次按同一规则分组，不需要重复整理。软件原有扫描触发方式保持一致：在图库目录放入新文件后，重新扫描即可入库。已有手动分类和分类重命名优先保留；素材详情选择“恢复自动分类”后重新按当前名称判断。重启软件后规则继续生效。

这不是图像识别或在线翻译。只有地点名、名称不明确或尚未收录关键词的素材进入其他环境，可手动分类；原图、文件夹、素材 ID 与收藏不因自动分组变化。

## 预览缓存

软件启动和成功扫描后，后台会逐步准备 HDR 卡片预览，按场景交错处理。前台查看请求优先，总解码并发限制为 2，减少大量原图同时解码造成的内存和磁盘争用。

卡片与常用详情共享 1024px 预览底图，更大的放大预览使用独立 2048px 底图；同一原图同时收到不同尺寸请求时合并处理。转换后的 WebP 缓存保存在软件目录 `data/thumbnails`，前台热点还使用最多 32MB 内存缓存。关闭、重启或切换分类不会要求重新解码已经准备好的卡片。

缓存按路径、原图纳秒修改时间、文件大小及内部算法版本区分。重新扫描未变图片会保留原有预览地址；图片改变后使用新缓存。缓存损坏可自动重建。缓存只保存显示用缩略图，不改动原始 HDR/EXR；Blender 渲染仍读取原图。

首次准备整个图库需要时间，后台会逐步完成。新增素材及首次打开尚未生成的大尺寸预览仍可能短暂等待。读取失败的单张素材会被跳过，不阻断其余图片。开发排查可读取本地 `/api/preview-cache`，查看本轮预生成的总数、成功数与失败数。

## 安装与配置

1. 保存并关闭 Blender，退出 SS 后台后，从 [1.8.0 发布页](https://github.com/XXLDinosaur/SurfaceStudio/releases/tag/v1.8.0) 下载并运行 `SurfaceStudio-Setup.exe`，选择原软件目录和要更新的 Blender 版本。安装器保留原 data 配置并备份旧插件。
2. 重开 SS，在「材质库设置 → HDR 环境图库」输入环境图目录，保存并重新扫描。可使用本机的 `G:\hdri素材\polyhaven`；这不是写死到软件中的默认路径。
3. 选择左侧「HDR」，搜索或预览环境，按住卡片预览图拖入 Blender 3D 视口，模型上或空白处松开均可。

HDR 图库必须与普通材质、贴图、法线、贴花和原生材质来源目录分开。支持递归读取 `.hdr`、`.exr`，每张文件独立入库；同一环境的不同格式不会自动合并。改名只修改对应图片及其名称记录，不改整个父文件夹。

## Blender 效果与撤销

当前场景获得一个独立 SS World：环境纹理连接背景，再连接 World 输出，默认强度 1、旋转 0。原有 World 节点不被清空，共享旧 World 的其他场景不变。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。

落点视口会启用场景世界，并从实体/线框模式切换到材质预览。Cycles 和 Eevee 渲染使用该场景世界；软件不会改变渲染引擎、相机、其他灯光或透明背景设置。若已启用透明背景，环境仍可照亮物体，渲染背景保持透明。Workbench 引擎不提供这种世界环境照明。

缩略图为经过 Reinhard 亮度映射的全景参考图，并非 Blender 的最终渲染。正式渲染使用原图，SS 不会把高动态范围原文件转为普通图片。保存 blend 后保留原文件引用；本功能不自动打包大型 HDR。移动工程前，可在 Blender「文件 → 外部数据」打包资源，或一起保留原图并重新定位路径。

HDR 环境只发往 Blender。拖到 SketchUp 会提示不支持。请更新到插件 1.4.0；旧插件会拒绝新版 HDR 拖放任务。

## 开发验证

设置 `PYTHONUTF8=1`，并将安装了 OpenImageIO/NumPy 的 `.desktop-runtime` 放入 `PYTHONPATH`。

后端：`python -m unittest test_preview_cache test_hdr_library`；原有隔离回归：`python tests/run_backend.py`。

真实 Blender 测试：在独立的 `BLENDER_USER_CONFIG/SCRIPTS/DATAFILES/EXTENSIONS` 临时目录下运行：

```text
blender --background --factory-startup --disable-autoexec --threads 2 --python-exit-code 1 --python test_hdri_blender.py -- <HDR素材目录> <测试输出目录>
```

构建独立预览输出，避免覆盖既有发布包：

```powershell
.\build.ps1 <Python路径> dist\hdr-preview
.\build_installer.ps1 <Python路径> dist\hdr-preview 'dist\hdr-preview\Surface Studio.exe'
```

软件构建依赖 OpenImageIO 3.2.2.0，构建脚本会收集其 DLL 和 NumPy 依赖。安装器 payload 使用明确文件清单，不包含用户 data 或私人素材。
