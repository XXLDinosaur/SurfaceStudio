# 素材导入指南

SS 读取磁盘上已有的贴图，不会把素材复制进软件目录。导入前先解压资源包，再在 **材质库设置** 中选择目录并扫描。目录层级和文件格式都会影响扫描结果。

**v1.4.0 新增法线贴图库，v1.3.0 没有这个入口。** 两种导入方式分别适合成套 PBR 材质和零散的法线贴图：

| 导入方式 | 扫描单位 | 目录规则 |
| --- | --- | --- |
| 普通材质库 | 一个子文件夹 = 一个材质 | 只读取根目录下一层材质文件夹内的图片，v1.4.0 仍保留这一限制 |
| 法线贴图库（v1.4.0） | 一张图片 = 一个法线资产 | 读取所选目录及其子目录中的支持格式图片，可直接选择放法线图的文件夹 |

两种资产会出现在同一个材质库界面，可以继续搜索、收藏、分类、加入集合或批量整理。

## 普通 PBR 材质库：选哪一层目录

选择 **包含各个材质子文件夹的根目录**。每个材质的贴图直接放在对应子文件夹内：

```text
我的材质库/                         ← 在 SS 中选择这一层
├─ Rock_4K/                         ← 一个材质
│  ├─ Rock_Preview.png              ← 可选预览图
│  ├─ Rock_4K_BaseColor.jpg
│  ├─ Rock_4K_Normal.png
│  ├─ Rock_4K_Roughness.jpg
│  └─ metadata.json                ← 可选，见下方说明
└─ Wood_4K/                         ← 另一个材质
   ├─ Wood_4K_BaseColor.jpg
   └─ Wood_4K_Normal.png
```

中文路径可以使用。没有 JSON、没有预览图或贴图通道不齐全的文件夹，也可以被索引；预览会优先使用名称包含 `preview` 的图片，其次是 `albedo` 图片，最后回退到扫描到的第一张支持格式图片。

**当前普通材质库只扫描根目录的下一层文件夹，不递归查找更深层的贴图。** 以下结构需要先整理：

| 选择方式或结构 | 当前结果 | 整理方法 |
| --- | --- | --- |
| 直接选择 `Rock_4K/`，里面都是贴图 | 根目录里的贴图不会作为普通材质导入，可能显示 0 个材质 | 选择它的上一级“我的材质库” |
| `我的材质库/岩石分类/Rock_4K/贴图.png` | 不会继续进入 `Rock_4K`，漏掉该材质 | 选择“岩石分类”目录，或将各材质文件夹放在同一根目录下 |
| `我的材质库/Rock_4K/textures/贴图.png` | 不会扫描 `textures` 中的贴图 | 将该材质的贴图直接放在 `Rock_4K` 中 |
| 多个材质的图片混放在同一个子文件夹 | 这些图片会被视为一个材质 | 按材质拆分为独立子文件夹 |
| 仅有 ZIP / RAR 压缩包 | 不会自动解压或读取包内素材 | 先解压，并检查解压后的层级 |

建议先用一两个材质子文件夹试扫，确认能显示后再导入整库。新增、删除或调整原始素材后，需要重新扫描。

## 纯法线贴图库：收集水波、涟漪等单张法线图

打开 **材质库设置 → 法线贴图库（每张图单独入库）**，填写可选的法线目录并扫描。这个目录内的每张支持格式图片都会单独作为一个法线资产入库，不要求名称含有 `Normal`，也不需要为每张图建立文件夹或提供 JSON。

```text
我的法线收藏/                       ← 填到“法线贴图库”
├─ 平静水面.png                     ← 独立资产
├─ 涟漪01.jpg                       ← 独立资产
└─ 海面/                            ← 会继续扫描子目录
   ├─ 大浪.png                      ← 独立资产
   └─ 细波.exr                      ← 可索引，界面不直接预览 EXR
```

法线目录可以独立于普通材质库，也可以是普通材质库中的一个专用子目录。**不能将普通材质库本身或它的上级目录设为法线目录。** 只把真实法线图放入这个目录：所有支持格式图片都会按 `Normal` 处理，混入的颜色图、粗糙度图或封面图也会被当作法线，不会自动判断图片内容。

日常使用：

1. 点击侧栏 **纯法线贴图**，或在顶部通道下拉菜单选择 **纯法线贴图**。
2. 点击卡片查看法线原图，使用平铺检视检查重复接缝与纹理分布。预览显示的是法线图本身，不是水面的渲染结果。
3. 像其他材质一样收藏、分类、加入“水波法线”等集合，也可通过批量整理统一操作。
4. 新增或删除法线文件后重新扫描。原始图片不会被改名、转换或移动。

普通材质库里 **仅含 Normal 通道** 的材质也会进入纯法线筛选。普通库仍按上面的文件夹层级和命名规则识别；“任意文件名、每图一个资产”的规则只适用于专门设置的法线贴图库。

**EXR 法线可以索引并将原文件发送给 Blender，但 SS 界面只显示预览占位提示。** 法线图库按每张图片独立索引，所以额外放入的 JPG / PNG 代理图也会作为另一条独立资产，不会与 EXR 自动合并。需要直接在 SS 里浏览时，可另存一份可预览格式；高精度 EXR 原文件可继续保留供 Blender 使用。

配套 **Blender 插件 1.1.0** 可将法线图接入新建基础材质的 Normal 节点，仍可使用现有的 DirectX 法线绿色通道翻转选项。该操作 **不会自动生成透明水材质，也不会把法线叠加到模型已有的水材质上**。如已有调好的水材质，请在 Blender 中把选定法线接入该材质的节点；水面的透明度、折射和其他参数仍由 Blender 材质设置控制。

法线资产也参与整理记录备份。恢复时按 **相对于法线图库根目录的路径（包含文件名）** 匹配，并与普通材质分开识别。例如 `海面/大浪.png` 必须保持相同相对路径；盘符和整个图库的外层位置可以改变，但文件改名、改扩展名或移动到不同子目录后将无法按原记录匹配。备份仍只含整理记录，不包含图片本身。

## 支持的文件格式

两种图库使用相同的支持扩展名。这里的“支持”指 SS 的文件扫描与预览，不代表会解析任何软件的专有材质文件。

| 文件格式 | 扫描索引 | SS 内预览 | 说明 |
| --- | --- | --- | --- |
| `.jpg` / `.jpeg` | 支持 | 支持 | 常用贴图及预览格式 |
| `.png` | 支持 | 支持 | 常用贴图及预览格式 |
| `.tif` / `.tiff` | 支持 | 支持常规可解码图像 | 缩略图不是原始高位深数据的精确显示 |
| `.exr` | 支持 | 不直接解码预览 | 普通材质可配套同通道代理图或预览图；独立法线资产显示占位提示，原文件可送到 Blender |
| `.webp` / `.bmp` / `.tga` / `.dds` / `.hdr` | 不支持 | — | 当前扫描器会忽略这些扩展名 |
| `.blend` / `.sbsar` 等软件材质文件 | 不解析 | — | 请先在原软件中导出支持格式的贴图 |
| `.zip` / `.rar` | 不读取包内素材 | — | 必须先解压 |

扩展名不区分大小写。不能通过直接改扩展名转换格式；需要转换时，请使用图像软件另存为支持格式。

## 普通材质的贴图通道与分类如何识别

普通材质库通过 **文件名关键字** 识别通道，不会分析图片内容。例如：

| 通道 | 文件名中识别的关键字（不区分大小写） |
| --- | --- |
| 颜色 | `albedo`、`basecolor`、`diffuse` |
| 法线 | `normal` |
| 粗糙度 | `roughness` |
| 高度 / 置换 | `displacement`、`height` |
| 金属度 | `metalness`、`metallic` |
| 环境遮蔽 | `_ao` |
| 透明度 | `opacity` |
| 高光 / 光泽 | `specular`、`gloss` |

没有匹配关键字的图片仍可被索引，但会显示为 `Other`，不能保证自动接到正确的 Blender 通道。例如，仅写 `nrm` 或将 `basecolor` 写成 `base_color`，当前规则不会识别为对应通道。

普通材质的自动分类主要来自材质子文件夹名称的第一个下划线之前的英文类别，例如 `Rock_4K`。未匹配内置类别时归入“其他”；可在 SS 中手动修改分类。文件夹名中的 `4K`、`8K` 等标记用于显示分辨率，它不是对每张图片实际像素的检测结果。

## 普通材质的 JSON 元信息是可选的

没有 JSON 也可以导入。当前读取的是每个材质文件夹中找到的第一个 `.json`，并按兼容的 Quixel / Megascans 风格字段读取；这不代表支持所有第三方 JSON 格式。

兼容的最小示例：

```json
{
  "name": "Rock Surface",
  "tags": ["rock", "stone"],
  "categories": ["surface", "rock"],
  "meta": []
}
```

顶层应为对象 `{}`，`tags`、`categories`、`meta` 应为数组；`meta` 中的条目应为包含 `key` 和可选 `value` 的对象。其他结构（如顶层数组、字段为 `null`、字段类型不兼容）可能导致跳过材质或扫描失败。一个目录里存在多个 JSON 时，也可能读到并非材质元信息的文件。

遇到此类问题，可先复制一个材质文件夹用于排查，将其中无关或不兼容的 JSON 移出测试目录，再重新扫描。不要为了导入而删除原始资源包中的元信息。

## 普通材质扫描为 0 或缺少材质时

1. 确认资源已解压，SS 选择的是包含材质子文件夹的根目录。
2. 确认贴图直接位于这些子文件夹中，没有多套一层分类目录或 `textures` 目录。
3. 检查扩展名是否在上面的支持列表里，且图片能够正常打开。
4. 用一个不含 JSON 的材质副本测试，排除元信息格式问题。
5. 检查该磁盘 / 网络目录是否在线，以及当前账号是否可以读取文件，再重新扫描。

法线贴图库不受普通材质的一层目录和文件名关键字限制。如果法线图未出现，先确认使用的是 v1.4.0 或更新版本，且路径填在 **法线贴图库** 输入框中，再检查格式、文件读取权限并重新扫描。只想查阅法线时，用“纯法线贴图”筛选。

SS 的缩略图使用已有图片，**不是实时渲染材质球**。成功导入、能够预览、Blender 能正确连接全部通道是三个不同环节；预览正常并不代表原始资源包含完整的 PBR 通道。
