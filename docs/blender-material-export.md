# Blender 自制材质保存与重装恢复

适用于 **SS 1.5.0 + Blender 连接插件 1.2.2**。

第一次使用可先看 [玻璃材质操作图解](glass-workflow.md)，包含 SS 与 Blender 实际界面截图。

## 从 Blender 一键添加

1. 打开 SS，在“材质库设置”中确认“材质库文件夹”。
2. “Blender 添加材质的保存位置”留空时，跟随上方材质库；也可填写其他已存在的文件夹。点击“保存并重新扫描”。
3. Blender 中选中物体，在材质槽中激活要保存的材质。
4. 在 3D 视图按 N，点击 **Surface Studio → 添加到 SS**。无需选择导出目录，名称沿用当前材质名称。
5. 插件保存节点与贴图，后台生成材质球预览，然后自动刷新 SS。新材质显示在 **未分类** 中，右键材质可修改分类。

需要 SS 正在运行。预览生成期间 Esc 可取消；文件保存完成后会等待 SS 刷新。若保存后 SS 关闭或暂时无法响应，文件仍在指定位置，重新扫描即可识别，无需重新导出。

## 文件存在哪里

例如你在 SS 中设置保存到 `G:\我的自制材质`：

```text
G:\我的自制材质\
  水面_随机编号\
    material.blend          # 原生材质，包含节点组和打包后的图片
    preview.png             # 标准材质球预览
    surface-material.json   # 名称、编号、材质数据名和 Blender 版本
```

每次保存新建一个独立子文件夹，不覆盖已有材质。请保留整个材质文件夹；不要仅复制预览图或单独修改说明文件。目录内不包含原场景模型。

当前材质库与自定义保存位置都会自动扫描。已有的其他材质包目录，也可在 **材质库设置 → Blender 自制材质库** 中添加，每行一个，递归识别。上方的普通 PBR 材质库保持原有用法。顶部筛选 **Blender 自制材质** 可单独查看，收藏、分类及批量操作照常使用。

## 重装或换电脑后

1. 保留独立材质库目录（若系统重装会格式化该盘，请先备份整个目录）。
2. 安装 SS 和配套 Blender 插件。
3. 在 SS 材质库设置中重新填写存放目录并扫描。无需旧 SS 安装目录、索引或原 Blender 工程，即可重新发现和赋予这些材质。

材质文件与整理记录是两回事：重装后仍能用材质，但要保留 SS 中的收藏和手动分类，需要提前用“材质库设置 → 整理备份与恢复”导出记录，再恢复到新安装。仅搬盘符且材质内部相对路径不变时可匹配。

## 重新赋予及支持范围

通过 SS 的“赋予到 Blender”或拖到视口网格上重新使用。插件加载保存的原节点图；SS 针对 PBR 贴图的平铺、AO、凹凸和法线翻转选项不会改写此节点图。原生材质需要插件 **1.2.0+**，并使用保存时的 Blender 主次版本或更高版本。例如 5.2 保存的材质不会发送到 4.2 使用。

支持静态原生材质：纯色、程序纹理、图片纹理、嵌套节点组及静态混合节点。贴图会打包保存，已修改但未另存的图片像素也会保存；原材质和原图片不被改写。预览是统一灯光、球体和 CPU Cycles 渲染，实际效果会随目标模型的 UV、尺度、属性、渲染引擎和灯光变化。

第一版明确拒绝动画/驱动、场景对象引用、OSL、UDIM、视频及图片序列。需要场景几何属性的节点仍要求目标模型提供相应属性。该功能保存 Blender 原生材质，不会将任意节点自动烘焙为可供其他软件使用的 PBR 贴图，也不索引任意散落的 `.blend` 工程。

实现使用 Blender 官方的 [材质数据块写入与加载接口](https://docs.blender.org/api/current/bpy.types.BlendDataLibraries.html)。

## 连接与重命名

Blender 已打开且插件启用时，点击 SS 顶部“Blender 未连接”即可发起连接；无需再进入帮助窗口。未启动 Blender 或未启用插件时会提示，连接不会赋予或修改场景材质。

“未分类”固定在列表最上面。右键材质 → 重命名可打开编辑窗口；双击卡片/详情的材质名称会原位编辑（回车或失焦保存、Esc取消），两种方式都可修改名称及对应文件夹（独立法线只改该图片文件名）。SS 的收藏、分类和备份匹配身份会保留，不覆盖同名文件夹。改名会生成隐藏的 .surface-studio.json 身份记录；搬迁时保留完整文件夹。其他工程直接引用旧磁盘路径时，需要重新定位资源。
