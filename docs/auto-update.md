# 软件更新（1.5.0）

SS 启动后会在后台检查官方 GitHub 的最新正式 Release，此后每 6 小时检查一次。不会把上传源码当成新版本，也不会降级到旧版本。

在「材质库设置 → 软件更新」中可手动检查、查看更新说明、关闭自动检查。发现新版后点击下载安装包，校验成功后再点击「安装并重启」。请先保存并关闭 Blender，以便安装器更新配套插件。安装器就绪后 SS 才退出；更新保持原安装位置及材质库配置、收藏、分类数据，材质资源仍保存在用户选择的位置。

断网时可稍后重试；下载不完整、文件被篡改或签名不正确时不会执行安装。插件安装失败时会保留安装报告供重试。首次使用此功能，需要手动安装包含更新功能的版本；旧版 1.4.0 无法自行获得此功能。

## 发布者流程

1. 更新软件版本号（含 updater.py 的 VERSION）、安装器版本信息及更新说明，构建软件和安装包。
2. 执行 `python sign_update.py --version v1.5.0`（替换为真实版本）。该命令对 dist/SurfaceStudio-Setup.exe 生成签名清单。
3. 在官方仓库发布同版本正式 Release，附上 `SurfaceStudio-Setup.exe`、`surface-update.json`、`surface-update.sig` 三个文件，并填写更新说明。签名后不得再修改安装包，修改后必须重新签名。

签名私钥位于本地 `.release-signing-private/update-ed25519.pem`，已被 Git 忽略。请单独安全备份，绝不能上传 GitHub、加入安装包或发给用户。客户端仅包含公钥。私钥丢失需要通过手动安装新客户端更换信任公钥。

1.5.0 是首个带签名更新支持的版本。已测试模拟新版、损坏下载、错误签名、网络失败、更新前确认、安装器就绪交接及配置保留；向下一正式版本的线上完整升级仍需未来版本发布后复验。
