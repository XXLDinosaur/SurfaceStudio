# Surface Studio 1.6.0 更新说明

2026-10-29 · Windows 桌面版 1.6.0 · Blender 插件 1.3.0

## 1. 素材分类更清晰

左侧统一为“素材分类”，一级是“未分类、材质、法线、贴花”。材质、法线、贴花下按素材名称自动归类，显示中文二级分类；点击箭头展开或收起。

英文名称使用本地词库识别，例如 Wall Crack → 裂缝、Drain Cover → 井盖、Metal Piece → 金属。无法识别时保留已有类别或进入未分类；用户手动归类优先。这是离线分类词库，不是任意英文名称的全文翻译。

从 Blender“添加到 SS”的材质先进入一级“未分类”，手动归类后进入材质下对应类别。移除重复法线入口和“Blender 自制材质”筛选／分类，原生材质功能继续保留。

![素材分类与材质浏览](../docs/images/v1.6.0/library.png)

## 2. 贴花直接拖到模型表面

在材质库设置中指定贴花图库。一份贴花一个文件夹，需要颜色贴图和 Opacity/Mask 遮罩；法线、粗糙度可选。

在对象模式下，把 SS 预览图拖到 Blender 模型表面，生成独立贴花对象，保留原模型材质与 UV。选中贴花按 G，或点击“沿表面移动贴花”，沿鼠标指向的模型表面滑动；左键／Enter 确认，右键／Esc 取消。移出模型时保持最后有效位置。

N 侧栏 → Surface Studio → 贴花调整，可修改尺寸、局部旋转、不透明度和表面偏移。旧贴花可点击“修复贴合 / 启用移动贴合”升级曲面贴合。投射前增加细分，降低面片穿入曲面导致的条状破面。

![独立测试场景：原材质与裂缝贴花](../docs/images/decals/comparison.png)

详细操作见 [贴花指南](../docs/decals.md)。普通“赋予到 Blender”入口会阻止贴花覆盖原材质。

## 3. 首次启动可查看本版本说明

首次使用和升级后的首次启动自动展示详细说明，同一版本关闭后不重复弹出。材质库设置最底部显示当前版本，可随时重新查看。修复分类下拉框中文字被裁切的问题。

![首次启动更新说明](../docs/images/v1.6.0/release-notes.png)

## 4. 1080p 与 Windows 缩放适配

启动窗口按所在屏幕的可用区域和 DPI 计算尺寸，并同步限制最小尺寸，给任务栏和屏幕边缘留出空间。字体和圆角不变。

已模拟检查 1080p 下 100%、125%、150% 缩放，以及标准／大字号的主界面、详情栏、设置和更新说明；已在当前显示器验证原生窗口尺寸。真实 1080p 显示器上的 DPI 行为仍需进一步实测。150% 加大字号时内容较拥挤，长说明及设置支持滚动。

## 安装与升级

1. 下载本次 Release 的 Windows 合集并完整解压。
2. 保存并关闭 Blender，退出旧 SS 后运行 SurfaceStudio-Setup.exe。
3. 选择原安装目录及需要更新插件的 Blender 版本。安装器保留用户数据并备份旧插件。
4. 打开 SS 查看本版本说明；素材仍保留在原有资源目录。

也可在 SS“材质库设置 → 软件更新”检查本次正式版本。更新包附带签名清单和 SHA-256 校验。

## 已验证与当前边界

- 本轮回归覆盖分类、导入、备份恢复、下拉框、说明阅读记录及窗口尺寸；贴花新增修复在 Blender 4.2 和 5.2 中验证。
- 先前跨版本基础贴花测试不能等同于本轮修复在所有版本及所有交互场景均已验证。
- 单张 PNG 的 Alpha 暂不自动识别为遮罩，图集暂不自动拆分。
- 复杂凹面、尖角、遮挡、不连续表面、过大的贴花或渲染位移仍可能需要手动调整；原生移动工具／直接修改坐标不使用专用表面滑动逻辑。
- 原有私人素材、配置、收藏和分类记录不随发布上传。
