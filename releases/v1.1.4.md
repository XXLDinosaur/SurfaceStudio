# Surface Studio v1.1.4 · Windows 自动安装版

SS **1.1.4**，配套 Blender 插件 **1.1.0**。本次汇总自 v1.0.1 以来的新增功能和修复。

## 新增与改进

- **Blender 插件自动安装**：识别常见安装位置、多版本与共享配置；可手动选择便携版。安装时启用插件、配置 SS 路径并验证重启加载，保留已有设置，安装失败可回退。
- **直接拖到 Blender 模型**：在对象模式下，将 SS 材质预览图拖到视口网格上松开，仅赋予落点模型，支持 Ctrl+Z 撤销。按钮赋材质和编辑模式选中面功能继续保留。
- **取消拖放修复**：在 Blender 以外的位置松开直接取消，阻止文件或链接拖放触发网页跳转；Esc 可取消。
- **只运行一个 SS**：再次双击唤起原窗口；最小化、点击关闭按钮隐藏后再启动，仍恢复同一个窗口，保留后台 Blender 连接。
- **外观**：保留较舒展的内部圆角与系统原生外框；不包含自定义外框裁切试验。

## 下载与安装

推荐下载 `SurfaceStudio-v1.1.4-Windows-x64-with-Blender.zip`，完整解压并运行 `SurfaceStudio-Setup.exe`。合集含配套插件 ZIP、中文安装与更新说明，不包含材质资源、用户设置或缓存。

发布页同时提供独立 `surface_studio_bridge.zip` 作为手动安装备用。`SHA256SUMS.txt` 用于校验下载文件。

已有用户先关闭 Blender 和旧 SS 后台进程，安装到原 SS 目录，保留 `data` 文件夹。旧版插件 1.0.0 需要升级至 1.1.0，自动安装器会一并处理。SS 需要 Windows 10/11 x64 和 WebView2 Runtime，无需另装 Python。

## 验证范围

- 本轮 32 项服务、插件通信、安装器、拖拽取消和单实例回归测试通过。
- Blender 4.2.4、4.2.9、4.3.0、5.1.2、5.2.0 已做插件功能测试；自动安装针对 4.2、4.3、5.1、5.2 正式版系列，未验证系列不自动安装。
- 完整跨窗口拖放在 Blender 4.2.4 LTS 经用户手动验收；其他版本完整手势未逐一手测。拖拽取消通过原生事件与网页防护回归测试，尚未追加完整手动取消验收。
- 安装后的重复启动、最小化恢复、隐藏后重新打开已实测，保持同一个窗口。

源材质按本地路径引用，移动工程时请保留贴图路径或在 Blender 中打包外部资源。
