# Surface Studio v1.3.0 · 批量整理与数据备份

SS **1.3.0** / Blender 插件 **1.1.0**。相较上次公开发布的 **v1.2.2**，本版包含 v1.2.3 的下拉菜单优化和新的整理功能。

## 与 v1.2.2 对比

| 功能 | v1.2.2 | v1.3.0 |
| --- | --- | --- |
| 材质整理 | 逐个修改分类、收藏和加入集合 | 多选后统一处理，支持 Ctrl/Cmd 点选、Shift 连选 |
| 全选范围 | 无批量全选 | 全选当前筛选结果，包含尚未滚动加载的材质 |
| 整理记录备份 | 需要手动保留 data | 创建 JSON 备份，操作前自动备份 |
| 换电脑恢复 | 需要自行处理数据文件 | 预览匹配数后合并恢复，允许素材库换盘 |
| 下拉选择 | 系统原生弹出菜单 | 日间/夜间玻璃菜单、勾选提示、键盘操作 |
| 开源许可 | 发布时未附正式许可 | GPL-3.0-only，允许商用，分发修改版须提供对应源码 |

## 1. 批量整理

点击工具栏“批量整理”，点选材质后统一修改分类、恢复自动分类、收藏/取消收藏或加入已有集合。Shift 连选，Ctrl/Cmd 可直接进入多选。选中数量会显示在操作栏，提交前再次确认。切换筛选后会清除不在结果中的选择；批量模式不启动 Blender 拖拽。

![批量多选与整理操作栏](https://raw.githubusercontent.com/XXLDinosaur/SurfaceStudio/v1.3.0/docs/images/v1.3.0/bulk.png)

## 2. 创建整理备份

左侧底部“整理备份与恢复”→“创建备份”。保存分类、分类改名、收藏、集合和最近浏览。点击“打开备份文件夹”，将 JSON 复制到其他磁盘或云盘。

![整理备份入口与备份范围](https://raw.githubusercontent.com/XXLDinosaur/SurfaceStudio/v1.3.0/docs/images/v1.3.0/backup.png)

## 3. 预览后合并恢复

换电脑后先导入素材库，再选择备份 JSON。按材质子文件夹名称匹配，盘符可以变化；子文件夹改名则无法匹配。未匹配记录跳过，之后补齐素材可再次恢复。恢复前显示匹配数量及归类冲突，截图数量为演示数据。

**采用合并恢复，不是覆盖回滚**：当前已有手动归类和分类名称优先保留，补充收藏及集合，不删除当前整理结果。批量操作和恢复前会自动创建备份，并使用写入恢复日志处理意外中断。

![恢复前的匹配与冲突预览（演示数据）](https://raw.githubusercontent.com/XXLDinosaur/SurfaceStudio/v1.3.0/docs/images/v1.3.0/restore.png)

**备份不包含贴图、预览缓存、外观偏好或 Blender 设置**。备份位于软件目录 `data/organization-backups`，不能代替原始贴图备份，建议另存到其他磁盘。

## 4. 统一玻璃下拉菜单

筛选、排序、卡片大小及分类选择统一采用圆角玻璃面板，支持上下键、回车确认、Esc 取消及点击外部收起，适配日间/夜间模式。

![新版玻璃下拉菜单](https://raw.githubusercontent.com/XXLDinosaur/SurfaceStudio/v1.3.0/docs/images/v1.3.0/dropdown.png)

## 下载与升级

下载 `SurfaceStudio-v1.3.0-Windows-x64-with-Blender.zip`，解压后运行 `SurfaceStudio-Setup.exe`。合集包含安装器、Blender 插件、中文说明、离线更新图解和 GPLv3 许可证，不含用户数据与材质贴图。

已有用户先关闭 Blender、退出 SS 后台进程，然后安装到原 SS 目录；保留 data。Blender 插件仍为 1.1.0，已有此版本无需单独更新。支持 Windows 10/11 x64 和 WebView2 Runtime，无需另装 Python。自动安装插件支持 Blender 4.2、4.3、5.1、5.2 正式版系列。

独立插件 ZIP 供手动安装备用；`SurfaceStudio-v1.3.0-Source.zip` 提供本版对应的项目源码和构建脚本，构建依赖见 README；`SHA256SUMS.txt` 用于校验下载文件。
