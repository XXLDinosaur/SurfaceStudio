# Surface Studio v1.2.2 · 分类管理与柔和日间模式

SS **1.2.2**，配套 Blender 插件 **1.1.0**。本次汇总自 v1.1.4 以来的更新。

## 新增与改进

- **手动修改材质分类**：右键材质 → 修改分类，或从详情面板进入；可归入已有分类，也可新建分类并归入，支持恢复自动分类。
- **创建分类**：侧栏“材质分类”旁点击 +；空的新分类也会保留显示。
- **重命名分类**：右键左侧分类名称 → 重命名分类。默认分类和自建分类均支持，侧栏、筛选、卡片及详情同步显示新名称，原有材质归属保持不变。
- **分类持久保存**：记录保存在 data/categories.json，按材质库路径隔离，重启及重新扫描后保留；不移动或重命名原始材质文件。
- **文字层级**：工作空间、材质分类、我的集合三个分组标题加大加重，比下方条目更突出。
- **柔和日间模式**：降低大面积纯白及玻璃高光，采用灰青配色和中性灰材质预览背景，提升浅色材质辨识度。夜间配色保持原样。

## 下载与安装

下载 `SurfaceStudio-v1.2.2-Windows-x64-with-Blender.zip`，完整解压后运行 `SurfaceStudio-Setup.exe`。合集包含 SS 自动安装器、Blender 插件 ZIP、中文安装使用说明、更新说明和文件校验值，不含个人材质库、用户数据或缓存。

安装器可检测并安装 Blender 4.2、4.3、5.1、5.2 正式版系列的连接插件；便携版可手动选择 blender.exe。独立的 `surface_studio_bridge.zip` 可作手动安装备用。本次插件版本仍为 1.1.0，已经安装此版本的用户无需单独更新插件。

已有用户请先关闭 Blender，并退出旧 SS 后台进程，再安装到原 SS 目录，保留 data 文件夹。安装器会保留数据并备份旧程序。Windows 10/11 x64，需要 WebView2 Runtime，无需另装 Python。
