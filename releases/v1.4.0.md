# Surface Studio v1.4.0 · 纯法线图库与导入指南

SS **1.4.0** / Blender 插件 **1.1.0**。为收集水波、涟漪等独立法线图增加专门入口，并回应“改为本地路径后检索不到素材”的反馈。

## 相比 v1.3.0

| 项目 | v1.3.0 | v1.4.0 |
| --- | --- | --- |
| 成套 PBR 材质 | 一个子文件夹一个材质 | 保留，仍只读取普通库下一层 |
| 零散法线收藏 | 同目录多图归为一个材质 | 专用法线库递归扫描，每张图一个素材，任意文件名 |
| 浏览法线 | 通道筛选混合完整材质，缺少单独平铺入口 | 纯法线筛选、原图、平铺查看 |
| 整理与备份 | 普通材质批量整理与备份 | 独立法线同样支持；按相对文件路径恢复 |
| 导入指引 | 简单目录示例 | 格式表、两类目录图、命名和JSON兼容排查 |

## 先选对目录层级

**不是只有 Bridge 资源才能导入。** 普通库读取 JPG、JPEG、PNG、TIF、TIFF、EXR 图片。分类借用了常见 Bridge 命名规则，未识别类别可手动修改。

普通库请选择“素材库”根目录，结构为“素材库 / 材质文件夹 / 贴图”。直接选择贴图所在文件夹，或多套“分类/textures”目录，都可能扫描为0。**本版没有把普通库改为递归扫描。**

![普通材质库与法线图库的目录示意](https://raw.githubusercontent.com/XXLDinosaur/SurfaceStudio/v1.4.0/docs/images/v1.4.0/import-structure.png)

支持格式、通道关键字与故障排查详见 [素材导入指南](https://github.com/XXLDinosaur/SurfaceStudio/blob/v1.4.0/docs/import-materials.md)。不直接解析 .blend、.sbsar、ZIP/RAR；WebP/BMP/TGA/DDS/HDR 暂未纳入扫描。

## 独立收集纯法线贴图

在“素材库设置”填写可选的“法线贴图库（每张图单独入库）”。目录及子目录内每张支持格式图片都按 Normal 导入，不需包含 normal 关键字，也不需JSON。仅放真实法线图，软件不会分析图像是否真的是法线。

目录可独立放在其他盘，或放在普通库的专用子目录；不能选普通库本身或它的上级。添加后点击侧栏“纯法线贴图”，或在顶部选择同名筛选。收藏、集合、手动分类和批量整理照常使用。

![每张法线都是独立素材（程序生成的演示图）](https://raw.githubusercontent.com/XXLDinosaur/SurfaceStudio/v1.4.0/docs/images/v1.4.0/normals.png)

## 法线原图与平铺检视

点击素材查看真实法线图，使用平铺检视检查接缝与分布。此预览是法线图本身，不是透明水面的实时渲染。普通库中仅含Normal通道的材质也支持此筛选与预览。

![法线平铺检视（演示图）](https://raw.githubusercontent.com/XXLDinosaur/SurfaceStudio/v1.4.0/docs/images/v1.4.0/normal-tiling.png)

EXR原图可索引及发送到Blender，SS不直接解码预览，显示明确占位；法线库中的每张JPG/PNG代理也会单独成为素材，不会自动与EXR合并。

## Blender 与迁移

无需更新插件版本，配套 **1.1.0** 可将法线接入新建基础材质。**不会自动生成透明水材质，也不把法线叠加到现有水材质。** 水的透明、折射和IOR需要在Blender中设置；也可复制法线文件路径，在现有材质节点中引用。OpenGL/DirectX绿色通道翻转沿用原有导入选项。

法线库换位置后，请通过整理备份恢复记录：备份按相对文件路径（含文件名）匹配，支持换盘；文件改名或移动到不同子目录则无法按旧路径恢复。切换完全不同的法线库不会因同名文件自动继承旧库记录。

## 下载与升级

下载 `SurfaceStudio-v1.4.0-Windows-x64-with-Blender.zip`，完整解压运行 `SurfaceStudio-Setup.exe`。含安装器、独立Blender插件、中文安装说明、素材导入指南、离线图解、GPLv3许可证。没有附带个人材质或数据。源码包与校验值分别提供。

已有用户先关闭Blender并退出SS后台，安装到原目录，保留data。Windows 10/11 x64，需要WebView2；无需Python。原插件1.1.0无需单独更新。
